## Editing Workflow

### Steps

1. Craft a text draft by hand (outside repository)
2. Refine and quality check via AI, ask critical Q&A, and fix mistakes
3. Rewrite by hand and incorporate fitting suggestions
4. Fix grammar, spelling, and style

### Checklist

- [ ] Content: Contact links – Formatted equally across all files
- [ ] Optional: Agent skills for review and quality improvements
- [ ] Review editor/ IDE suggestions (according to enabled tools)
- [ ] [LanguageTool](https://languagetool.org) for final grammar and spelling
- [ ] Run NPM tooling available, e.g., `cSpell` – UK spelling
